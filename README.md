專為「Fit21 ✕ 遇見喜樂營養俱樂部」學員設計的健康飲食管理系統。免去繁瑣查表與磅秤，直覺記錄每日蛋白質與熱量！

---

## 🚀 如何發布到 GitHub Pages 免費提供客戶使用（3分鐘教學）

你可以透過 GitHub 提供的 **免費 GitHub Pages 靜態網站代管服務**，只要將本資料夾內的 `index.html` 上傳，就能獲得一個專屬網址（例如：`https://你的帳號.github.io/fit21-tracker/`），隨時可以把連結貼到 LINE 官方帳號或客戶群組！

### 步驟 1：在 GitHub 建立新儲存庫 (Repository)
1. 登入 [GitHub.com](https://github.com/)。
2. 點擊右上角的 **「+」** 按鈕，選擇 **「New repository」**。
3. **Repository name**（專案名稱）輸入：例如 `fit21-tracker`。
4. 設定為 **Public**（公開）。
5. 點擊最下方的 **「Create repository」**。

---

### 步驟 2：上傳專案檔案（共 3 個檔案）
1. 在剛建立好的專案頁面中，點擊 **「uploading an existing file」**（或直接把檔案拖曳進網頁中）。
2. 將此資料夾中的 **`index.html`、`icon.png`（精美圖示）、`manifest.json`** 3 個檔案一起拖曳上傳。
3. 點擊綠色的 **「Commit changes」** 完成儲存。

---

### 步驟 3：開啟 GitHub Pages 免費發布
1. 在專案上方選單點選 **「Settings」**（設定）。
2. 在左側選單中找到 **「Pages」**。
3. 在 **Branch** 下拉選單中：
   * 將 `None` 切換成 **`main`**（或 `master`）。
   * 後方資料夾保持 `/ (root)`。
   * 點擊 **「Save」**（儲存）。
4. 等待約 1~2 分鐘後重新整理頁面，頂部就會出現一組公開網址：
   > 🌐 **`https://<你的帳號>.github.io/fit21-tracker/`**

## ✨ 系統特色
- **個人生理指標與目標換算**：自動依體重、年齡、性別、生活型態試算 BMR / TDEE 與每日蛋白質建議目標。
- **雙軌儀表板**：同步追蹤「蛋白質達標率」與「熱量預算」，直覺掌控減脂與增肌進度。
- **全方位常見食物分類庫**：
  - 🥤 **營養奶昔 (9g 蛋白質 / 88 kcal)**：支援快速份數累加
  - 🍚 **優質碳水主食**：白米飯、糙米飯、熟地瓜、燕麥片、玉米、馬鈴薯
  - 🥦 **健康青菜蔬菜**：清燙青菜、炒青菜、綠花椰菜、生菜沙拉、綜合菇類
  - 🧀 **起司與蛋奶類**：高鈣起司片、起司條、茶葉蛋、鮮乳、希臘優格
  - 🍗 **生活外食與炸物**：超商舒肥雞胸、麥當勞純牛肉片、鹽酥雞、傳統香雞排
- **多元彈性計量單位**：支援「份/碗/顆」、「手掌視覺估算」、「公克 (g) 秤重」、「毫升 (ml) 容積」。
